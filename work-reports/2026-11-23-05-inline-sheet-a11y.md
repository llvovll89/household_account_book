# 인라인 시트·모달에 공통 모달 동작 적용

- 날짜: 2026-11-23
- PR: #43

## 한 줄 요약
목표·메모·구독·거래 목록·달력 화면에서 직접 띄우던 시트·모달 8곳이 Escape로 닫히고, 포커스가 시트 안에 머물며, 스크린리더가 대화상자로 읽도록 바꿨습니다. 붙어 있던 수정·삭제 버튼도 키웠습니다.

## 왜 했나
- 별도 모달 파일 22개는 `useModalClose`를 쓰지만, 화면 안에 조건부로 그리던 시트·모달 8곳은 쓰지 않았습니다.
  - 목표 저금/인출, 목표 추가·수정, 메모 날짜 상세, 메모 입력, 구독 추가·수정, 일괄 카테고리 변경, 영수증 보기, 달력 날짜 내역
- 그래서 `role="dialog"`, Escape 닫기, 포커스 가두기, 닫은 뒤 포커스 복귀, 배경 스크롤 잠금이 모두 없었습니다.
- 목표·구독의 수정·삭제 버튼과 메모 상세 닫기 버튼이 28px로 붙어 있어 잘못 누르기 쉬웠습니다.

## 무엇을 바꿨나
- `components/ui/InlineDialog.tsx`를 추가했습니다. 바깥 영역·배경 클릭 영역·`role="dialog"` 패널을 그리고 `useModalClose`를 붙입니다.
  - 인라인 시트는 닫힘 애니메이션이 없으므로 `duration: 0`으로 지연 없이 닫습니다.
- 위 시트들을 `InlineDialog`로 감쌌습니다. 기존 클래스(배경색, `modal-backdrop`·`modal-panel` 애니메이션)는 그대로 넘겼습니다.
- 수정·삭제·닫기 버튼을 28px에서 36px로 키웠습니다.
  - WCAG 2.2 AA 최소 기준(24px)은 이미 넘었지만, 붙어 있는 버튼이라 오터치를 줄이려고 키웠습니다.
  - 메모 달력의 날짜는 칸 전체(높이 58px)가 버튼이라 그대로 뒀습니다.

## 확인한 방법
- `InlineDialog` 테스트 추가: 대화상자 이름과 `aria-modal` 노출, Escape로 닫힘, 패널 안 클릭으로는 닫히지 않음
- `npm run verify` 통과(테스트 276개)

## 남은 일·주의
- 감싼 시트의 자식 들여쓰기는 한 단계 깊게 남아 있습니다. 동작에는 영향이 없습니다.
- 시트 화면은 직접 열어 Escape와 Tab 순환을 한 번 확인해 주세요.
