# 목표 자동 집계 로직을 lib/로 분리하고 테스트

- 날짜: 2026-11-23
- PR: #49

## 한 줄 요약
GoalsView 안에 있던 목표 자동 집계와 최근 연결 내역 계산을 `lib/goals.ts`로 옮기고 테스트를 붙였습니다. 동작은 바뀌지 않습니다.

## 왜 했나
- 기술부채 감사 3번 항목입니다(큰 컴포넌트의 계산 로직에 테스트가 없음).
- #42에서 고친 집계 부호 버그도 컴포넌트 테스트가 없어 코드로만 확인했었습니다.
- 같은 연결 판정 필터가 두 `useMemo`에 복사돼 있었습니다.

## 무엇을 바꿨나
- `isLinkedToGoal`, `getGoalAutoAmounts`, `getRecentLinkedTransactions`를 추가했습니다.
- GoalsView는 이 함수들을 `useMemo`로 감싸서 씁니다.

## 확인한 방법
- 테스트 4개 추가
  - 지출 카테고리 연결 목표가 +로 쌓임(#42 회귀 방지)
  - 태그만 연결하면 순액으로 계산
  - 카테고리와 태그를 모두 지정하면 둘 다 맞아야 함
  - 최근 연결 내역 순서
- `npm run verify` 통과(테스트 283개)
