# 앱 내 알림 센터

- 날짜: 2026-11-23
- PR: #55

## 한 줄 요약
헤더에 종 아이콘을 추가했습니다. 오늘·내일 결제 예정, 예산 80%·100% 도달, 2일 이상 기록 공백을 모아 보여줍니다.

## 왜 했나
- 기능 분석 F7 항목입니다.
- 교수님이 '앱 내 알림 센터' 방식을 고르셨습니다. 서버 푸시와 브라우저 알림 권한은 쓰지 않습니다.

## 무엇을 바꿨나
- `lib/notifications.ts`의 `buildNotifications`가 알림을 만듭니다.
  - 구독: 오늘·내일 결제(연간 주기 반영)
  - 월간 정기 지출: 이번 달 미적용이면서 오늘·내일인 항목
  - 신용카드: 결제일이 오늘·내일
  - 예산: 이번 달 80% 이상, 100% 이상(단계별로 한 번)
  - 기록 공백: 마지막 기록이 2일 이상 전(기록이 하나도 없는 새 사용자는 제외)
- `NotificationCenter`(헤더 메뉴 왼쪽)
  - 개수 배지를 보여주고, 누르면 알림 목록 시트(`InlineDialog`)가 열립니다.
  - 알림은 하나씩 확인하거나 '모두 확인'으로 닫을 수 있습니다.
  - 닫은 알림 id는 이 기기의 localStorage에만 기억합니다. id에 날짜·단계가 들어 있어 다음 날이나 다음 단계에는 다시 뜹니다.

## 확인한 방법
- 테스트 4개 추가
  - 결제 예정 우선순위
  - 예산 80% 단계 id
  - 기록 공백과 새 사용자 제외
  - 배지·목록·닫기 기억
- `npm run verify` 통과(테스트 299개, 홈 시작 번들 162KB → 165KB)

## 남은 일·주의
- 앱이 닫혀 있을 때 오는 알림은 없습니다(서버 푸시가 필요함).
- 주간·격주 정기 지출은 알림 대상에서 뺐습니다.
