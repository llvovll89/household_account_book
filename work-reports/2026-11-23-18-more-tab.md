# 하단 탭 6개 → 4개 (더보기)

- 날짜: 2026-11-23
- PR: #56

## 한 줄 요약
하단 메뉴를 홈·거래 내역·분석·더보기 4개로 줄였습니다. 목표·구독·메모는 '더보기'로 들어간 뒤 화면 위 전환 버튼으로 오갑니다.

## 왜 했나
- UX 분석 U4 항목입니다.
- 390px 화면에서 탭 6개는 탭당 약 65px에 라벨 10px였습니다.
- 교수님이 '메모·구독·목표를 더보기로' 안을 고르셨습니다.

## 무엇을 바꿨나
- `LEDGER_TABS`는 3개로 줄이고, 목표·구독·메모는 `MORE_TABS`로 묶었습니다.
- '더보기' 메뉴는 마지막으로 연 목표·구독·메모 화면을 엽니다(처음에는 목표). 세 화면 중 어디에 있든 '더보기'가 현재 위치로 표시됩니다.
  - `BottomNavigation`에 `matches` 속성을 추가해서 이 표시를 처리합니다.
- 세 화면 위에 '목표 | 구독 | 메모' 전환 버튼(`aria-pressed`, 높이 44px)을 추가했습니다.
- 탭 값(`Tab`)과 PWA 바로가기 주소는 그대로라서, 기존 링크와 저장된 마지막 탭도 그대로 동작합니다.

## 확인한 방법
- 더보기 활성 표시와 이동 대상 테스트 추가
- `npm run verify` 통과

## 남은 일·주의
- 데스크톱 왼쪽 메뉴도 같은 4개 메뉴를 씁니다.
- 직접 써 보고 목표·구독·메모 순서를 바꾸고 싶으면 `MORE_TABS` 순서만 바꾸면 됩니다.
