# 계좌별 실제 잔액

- 날짜: 2026-11-23
- PR: #52

## 한 줄 요약
현금·체크카드·계좌에 '오늘 기준 잔액'을 입력하면, 이후 기록으로 계좌별 현재 잔액과 합계를 보여줍니다. 지금까지 '순자산'은 앱에 적은 수입 − 지출 누적일 뿐이라 실제 통장 잔액과 달랐습니다.

## 왜 했나
- 기능 분석 F3 항목입니다. 교수님이 '시작 잔액 + 계좌별 잔액' 범위로 정하셨습니다. 이체 유형은 이번 범위에서 뺐습니다.

## 무엇을 바꿨나
- **데이터:** `UserPaymentMethod`에 `openingBalance`(잔액)와 `balanceAsOf`(기준일)를 추가했습니다. 기준일까지의 거래는 입력한 잔액에 이미 들어 있다고 봅니다.
  - 백업 검증 스키마에도 두 필드를 추가했습니다. 추가하지 않으면 복원할 때 필드가 지워집니다.
  - 마이너스 통장을 위해 음수도 허용합니다.
- **계산:** `lib/accountBalances.ts`의 `getAccountBalances`를 추가했습니다.
  - 잔액 = 입력한 잔액 + 기준일 다음 날부터의 수입 − 지출
  - 거래에 계좌 id가 없는 예전 기록은 같은 종류의 첫 계좌로 셉니다.
  - 신용카드는 제외합니다.
- **결제수단 관리:** 현금 행에 잔액 수정 버튼을 추가했습니다. 체크카드·계좌 편집에는 '오늘 기준 잔액(선택)' 입력을 넣었습니다. 잔액 값을 바꿀 때만 기준일이 오늘로 옮겨집니다.
- **월간 대시보드:** 잔액을 입력한 계좌가 있으면 카드 제목이 '계좌 잔액 합계'가 되고 계좌별 잔액 목록을 보여줍니다. 입력한 계좌가 없으면 기존 화면에 '잔액 입력' 안내 링크를 추가했습니다. 기존 '누적 잔액' 칸은 뜻이 드러나도록 '누적 수입−지출'로 이름을 바꿨습니다.
- **병합:** 로컬 결제수단에 잔액을 입력했다면 기본값으로 보지 않습니다. 그래서 로그인 병합 때 잔액이 사라지지 않습니다.

- 6개월 추이 그래프는 여전히 수입−지출 누적 기준입니다.
