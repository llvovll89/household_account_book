# 전체 기간 검색과 메뉴 진입 경로 정리

- 날짜: 2026-11-23
- PR: #45

## 한 줄 요약
거래 검색에 '전체 기간' 범위를 추가했습니다. 로그인 여부와 관계없이 같은 메뉴에서 가져오기·결제수단·자동 분류 규칙·백업·초기화를 열 수 있게 했습니다.

## 왜 했나
기능·UX 분석에서 찾은 항목입니다.
- **검색이 이번 달로 한정:** 검색이 보고 있는 달의 내역만 돌아서 "작년 넷플릭스" 같은 검색이 안 됐습니다.
- **진입 경로가 흩어짐**
  - 백업·복원은 사용 가이드 안에서만 열렸습니다.
  - 자동 분류 규칙과 결제수단 관리는 로그인 메뉴에만 있었습니다.
  - 반대로 로그아웃 상태 헤더에는 '전부 초기화' 버튼이 바로 노출돼 있었습니다.

## 무엇을 바꿨나
- 검색창 아래에 `이번 달 | 전체 기간` 토글을 추가했습니다.
  - 전체 기간이면 모든 내역에서 찾고, 일·주 보기 범위도 무시합니다.
  - 기본값은 이번 달이고, 검색어가 없으면 영향이 없습니다.
- 헤더 메뉴 하나를 로그인 여부와 관계없이 씁니다.
  - 로그아웃 상태에서는 메뉴 아이콘이, 로그인 상태에서는 프로필이 메뉴를 엽니다.
  - 메뉴 항목은 가져오기, 결제수단 관리, 자동 분류 규칙, **백업·복원(신규 진입점)**, 구분선 아래 전부 초기화, (로그인 시) 로그아웃입니다.
  - 로그아웃 상태 헤더의 가져오기·초기화 아이콘 버튼은 메뉴 안으로 옮겼습니다.

## 확인한 방법
- 다른 달 내역이 '전체 기간'에서만 검색되는 테스트를 추가했습니다.
- `npm run verify` 통과

## 남은 일·주의
- 메뉴 항목 이름·순서는 직접 보고 조정해 주세요.
- 하단 탭 6개를 5개 이하로 줄이는 것(U4)은 정보 구조 변경이라 이번 범위에서 제외했습니다.
