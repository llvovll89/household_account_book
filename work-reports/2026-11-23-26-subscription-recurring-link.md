# 구독과 정기 내역 연결 (자동 기록)

- 날짜: 2026-11-23
- PR: #64

## 한 줄 요약
구독을 추가하거나 수정할 때 '결제일마다 지출로 자동 기록'을 켜면 연결된 정기 내역이 만들어집니다. 그 정기 내역이 결제일에 지출을 자동으로 기록합니다.

## 왜 했나
- 구독 목록은 거래를 만들지 않는 독립 목록이라, 같은 결제를 정기 내역에도 따로 등록해야 했습니다.
- 그렇게 두 곳에 등록하면 예고와 알림이 두 번씩 떴습니다.

## 무엇을 바꿨나
- **데이터:** `Subscription.recurringId`를 추가하고 백업 스키마에도 반영했습니다.
- **`lib/subscriptions.ts`**
  - `canAutoRecord`: 매월·원화 구독만 자동 기록할 수 있습니다(정기 내역이 월간·원화 기준이라서).
  - `syncSubscriptionRecurring`: 토글 상태에 따라 연결된 정기 내역을 만들거나, 이름·금액·카테고리·결제일을 맞추거나, 지웁니다.
  - 새로 연결할 때 이번 달 결제일이 이미 지났으면 이번 달은 '적용됨'으로 둡니다. 이미 직접 적었을 수 있어서 중복 등록을 막으려는 것입니다.
- **구독 화면**
  - 입력 시트에 토글을 추가했습니다. 연간·USD 구독이면 비활성화하고 이유를 보여줍니다.
  - 구독을 지우면 연결된 정기 내역도 함께 지웁니다.
  - 정기 내역 화면에서 연결 항목을 지웠다면, 수정할 때 토글이 꺼진 상태로 보입니다.
- **알림 센터:** 자동 기록으로 연결된 구독은 정기 지출 알림 한 번만 띄웁니다.

## 확인한 방법
- 테스트 5개 추가
  - 연결 생성(결제일 전·후)
  - 수정 반영과 USD 전환 시 해제
  - 알림 중복 방지
  - 화면에서 생성·삭제 연동
- `npm run verify` 통과

## 남은 일·주의
- 연결된 정기 내역의 결제수단은 기본값(현금)입니다. 정기 내역 화면에서 카드로 바꿔 주세요.
- 이미 따로 등록해 둔 정기 내역과 자동으로 합치지는 않습니다. 토글을 켜기 전에 기존 항목을 지워야 중복되지 않습니다.
