# 병합·동기화·정기내역에서 데이터가 사라지거나 중복되는 문제 수정

- 날짜: 2026-11-23
- PR: #40

## 한 줄 요약
code-review(xhigh)에서 찾은 동기화·정기내역 버그 7건을 고쳤습니다. 로그인 병합 때 카드가 기본값으로 덮이는 문제, 회원가입 뒤 남은 모달에서 로컬 데이터가 지워지는 문제, 오프라인 정기내역 중복 등입니다.

## 왜 했나
- **결제수단 덮어쓰기:** 로컬 설정은 빈 결제수단을 항상 기본 3종으로 채웁니다. 그래서 병합하면 계정의 카드(결제일 포함)가 기본 3종으로 바뀌었습니다. 스와이프 감도와 숨긴 위젯도 로컬 기본값이 이겼습니다.
- **회원가입 후 데이터 삭제:** 회원가입은 자동 로그인 뒤 바로 로그아웃합니다. 이때 병합 모달이 떠 있는 채로 남았고, 거기서 '삭제 후 계속'을 누르면 로컬 모드의 원본 데이터가 지워졌습니다.
- **정기내역 중복:** 원격 저장이 실패하면 화면에서만 거래를 롤백했습니다. 로컬 캐시와 미동기화 기록에는 거래가 남았는데 기준 월은 그대로여서, 다음 온라인 실행 때 거래가 올라가고 같은 항목이 다시 자동 적용됐습니다.
- **실패해도 성공 안내:** 정기 항목 등록이 실패해도 '자동 등록' 토스트와 결과 모달이 떴습니다.
- **태그 변경 시 미동기화 거래 유실:** 태그 이름 변경·삭제가 원격 목록을 다시 읽어 저장했습니다. 그래서 아직 올라가지 않은 로컬 거래가 사라졌습니다.
- **'내 변경 재시도' 후 화면 불일치:** 원격에는 내 데이터가 저장되는데 화면은 다른 기기 데이터로 남았습니다. 그 상태에서 다음 편집을 하면 방금 지킨 변경이 덮어써졌습니다.
- **시간대 차이로 중복 등록:** 다른 시간대 기기가 다음 달분을 먼저 적용하면 이번 달이 다시 '도래'로 판정됐습니다.

## 무엇을 바꿨나
- 병합 규칙
  - 로컬 결제수단이 기본 3종 그대로면 계정 값을 씁니다.
  - 로컬에서 직접 만든 카드가 있으면 id 기준으로 계정 카드와 합칩니다.
  - 스와이프 감도는 계정 값, 숨긴 위젯은 로컬에 값이 있을 때만 로컬 값을 씁니다.
- 로그아웃 콜백에서 병합 모달을 닫습니다. '삭제 후 계속'은 로그인 상태에서만 로컬을 비웁니다.
- 정기내역 적용은 거래와 기준 월을 함께 진행하고 `persist`로 저장합니다. 결과는 성공 여부(boolean)로 돌려줘서, 호출부는 성공했을 때만 안내합니다.
- 태그 변경·삭제는 화면 상태 기준으로 저장합니다(다른 핸들러와 같은 방식).
- 재시도가 성공하면 데이터를 다시 불러와 화면을 원격과 맞춥니다.
- 월간 도래 판정을 `!==`에서 `<`로 바꿨습니다.
