# CLAUDE.md 갱신과 문서 정리

- 날짜: 2026-11-09
- PR: #35

## 한 줄 요약
실제 코드와 달라진 `CLAUDE.md`를 현재 구조에 맞게 고치고, 루트에 흩어진 문서를 `docs/`로 모았습니다. 기술부채 감사 결과도 저장소에 남겼습니다.

## 왜 했나
- 기술부채 감사 2번 항목입니다.
- `CLAUDE.md`는 이 저장소에서 작업하는 AI가 가장 먼저 읽는 문서입니다. 그런데 존재하지 않는 `useTransactions.ts`를 핵심 CRUD 훅으로 소개하고 있었고, 주요 훅(`useAppHandlers`)과 lib 모듈 대부분이 빠져 있었습니다. 카테고리 상수(대출·보험 누락)와 핵심 타입 설명도 실제와 달랐습니다.
- 오늘 바뀐 규칙도 반영되지 않았습니다. 동기화 기록 구조, Auth 초기화 방식, 첫 페인트 전 테마 적용, 작업 보고서 규칙이 그렇습니다.
- 루트에 점검·리뷰 문서 6개가 흩어져 있어 어떤 문서가 현재 기준인지 알기 어려웠습니다.

## 무엇을 바꿨나
- `CLAUDE.md`를 다시 썼습니다. 실제 폴더 구조, 명령어(`npm run verify`), 이중 스토리지와 동기화 기록 구조, 날짜 규칙(UTC 파싱 금지와 말일 보정), 테마·폰트 규칙, 작업 흐름(PR·보고서·커밋 메시지)을 담았습니다. 기존 UI 컨벤션과 "하지 말 것"은 유지하고, 태그·Auth 관련 규칙만 현재 코드에 맞게 고쳤습니다.
- 루트 문서 6개(`RETENTION_IMPROVEMENTS`, `SEO`, `UI_UX_AUDIT_2026-10-19`, `UNCOMMITTED_REVIEW`, `USAGE_MEASUREMENT`, `UX_REVIEW`)를 `docs/`로 옮겼습니다. 서로 파일명으로만 참조하고 있어서 링크는 깨지지 않습니다.
- `docs/tech-debt-audit-2026-11-09.md`를 추가했습니다(감사 결과와 단계별 계획).
- `AGENTS.md`는 다른 에이전트용 작업 지침이라 손대지 않았습니다.

## 확인한 방법
- `CLAUDE.md`에 적은 파일·함수·타입 필드가 실제로 있는지 파일 목록과 코드를 대조했습니다.
- 옮긴 문서를 코드·스크립트·설정에서 참조하는 곳이 없는지 검색했습니다.
- `npm run verify`를 통과했습니다.

## 남은 일·주의
- `AGENTS.md`의 "승인된 작업 순서" 항목은 예전 작업 기준이라 오래됐습니다. 계속 쓰실지 정리할지 결정이 필요합니다.
