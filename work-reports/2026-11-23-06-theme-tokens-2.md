# 테마 토큰 2단계: Analytics·TransactionList

- 날짜: 2026-11-23
- PR: #44

## 한 줄 요약
분석 화면과 거래 목록의 hex 색상 클래스 473곳을 테마 토큰으로 바꿨습니다. 라이트 모드에서 hover 시 어두운 회색이 되거나 글자가 흐리던 변형 클래스가 테마를 따라갑니다.

## 왜 했나
- 1단계(#38) 다음 순서입니다. 두 파일에는 hex 클래스가 각각 255곳, 247곳으로 가장 많았습니다.
- `interface.css`의 라이트 테마 덮어쓰기는 기본 클래스에만 걸립니다. `hover:`·`/20` 같은 변형은 라이트에서도 다크 색으로 그려졌습니다.

## 무엇을 바꿨나
- `scripts/migrate-theme-tokens.mjs`로 Analytics 248곳, TransactionList 225곳을 치환했습니다.
- 스크립트 표에 없던 7종 13곳은 직접 정했습니다.
  - `hover:bg-[#2C2C2E]` → `hover:bg-tone-chip`(다크 값 같음)
  - `hover:text-[#C8D1DC]` → `hover:text-fg`, `placeholder-[#9CA6B3]` → `placeholder-muted`
  - `text-[#B9C0C8]`·`text-[#6F7D90]` → `text-muted`, `text-[#5A8EC8]` → `text-accent`, `bg-[#9CC7FF]/20` → `bg-tone-blue/20`
  - 이 7종은 다크에서 미세하게 달라집니다. 회색·파랑 계열 안에서 밝기만 조금 바뀝니다.
- 두 파일을 ESLint 토큰 규칙 대상에 추가했습니다.
- **#42 되돌림:** 리뷰가 "#38 때 현금·체크 잔액 라벨이 초록·청록에서 파랑으로 바뀌었다"고 지적해 #42에서 되돌렸습니다. 그런데 `interface.css:241`이 예전 `text-[#A8EEC4]`·`text-[#92E6D9]`를 원래부터 두 테마 모두 `var(--accent)`로 그리고 있었습니다. 즉 #38은 화면을 그대로 옮긴 것이고, 지적은 오탐이었습니다. 그래서 `text-accent`로 다시 돌려놨습니다.
