# App.tsx 분리 1단계: 동기화·저장 재시도·충돌 처리 훅

- 날짜: 2026-11-23
- PR: #57

## 한 줄 요약
App.tsx에서 원격 저장(`persist`), 실패 재시도, 저장 충돌, 온라인·동기화 상태 묶음을 `hooks/useSyncPersistence.ts`로 옮겼습니다. App.tsx는 2,769줄에서 2,248줄로, `useState`는 54개에서 35개로 줄었습니다. 동작은 바뀌지 않습니다.

## 왜 했나
- 기술부채 감사 6번 항목(App.tsx 비대)입니다.
- 이 묶음은 상태 약 20개와 함수 10개가 서로만 참조하는 덩어리였습니다. 그래서 가장 먼저 떼어내기 좋았습니다.

## 무엇을 바꿨나
- 스크립트로 해당 상태·effect·콜백을 이름을 바꾸지 않고 그대로 옮겼습니다. 그래서 App의 JSX는 바뀌지 않았습니다.
- 이 묶음에서만 쓰는 상수·타입·헬퍼도 함께 옮겼습니다.
  - 충돌 선호 키, 마지막 동기화 시각 키
  - `parseConflictScopePreference`, `FailedPersistTask` 등
  - App에서도 쓰는 `getDefaultSelectedConflictKeys`, `scopeLabel`, `RetryReasonCode`는 export합니다.
- App에서 쓰지 않는 setter 11개는 훅 밖으로 내보내지 않습니다.
- 훅 의존성은 `hydrateData` 하나뿐입니다.
- 이 묶음에는 테스트가 없었습니다. 그래서 동작을 고정하는 훅 테스트를 추가했습니다.
  - 저장 실패 → 대기열·미동기화 표시 → 재시도 성공 → 표시 해제
  - 충돌 → 충돌 모달·충돌 키

## 확인한 방법
- 새 훅 테스트 2개를 5번 반복 실행해 모두 통과했습니다(처음 작성한 버전이 상태 반영 순서 때문에 가끔 실패해서 고쳤습니다).
- `npm run verify` 통과(테스트 302개, lint 경고 0)
