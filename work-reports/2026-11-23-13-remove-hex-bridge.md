# interface.css의 hex 브리지 규칙 정리

- 날짜: 2026-11-23
- PR: #51

## 한 줄 요약
테마 토큰 이전(#38·#44·#47·#48)이 끝나 더 이상 쓰이지 않는 `interface.css`의 hex 클래스 덮어쓰기 규칙 14줄을 지웠습니다. 화면은 바뀌지 않습니다.

## 왜 했나
- 이 규칙들은 `[class~="bg-[#1C1C1E]"]`처럼 hex 클래스 이름을 찾아 테마 색으로 바꾸던 임시 다리였습니다.
- 이제 `.ts`·`.tsx`·`.html` 어디에도 해당 클래스가 없습니다(32개 선택자 전부 grep 0건).
- 남겨두면 새 코드가 다시 hex 클래스를 쓰고 "왜인지 테마가 맞는" 상황을 만들 수 있습니다.

## 무엇을 바꿨나
- hex 선택자만 있던 규칙 14줄을 지웠습니다.
- 다른 선택자와 묶여 있던 3줄은 쓰이는 부분만 남겼습니다.
  - `[class~="text-white"]` → 라이트에서 본문색으로 바꾸는 규칙은 유지
  - 액션 버튼 hover → `button[class~="bg-action"]:hover`
  - 대시보드 카드 테두리 → `.dashboard-grid > .bg-surface`
- 판정 근거가 없어진 `scripts/migrate-theme-tokens.mjs`에는 기록용이라는 주석을 달았습니다.

## 확인한 방법
- 지운 선택자 32개가 코드에서 0건인 것을 확인했습니다.
- `npm run verify` 통과(테스트 283개)

## 남은 일·주의
- `text-white`는 라이트에서 본문색(어두운 글자)으로 바뀌는 규칙이 여전히 있습니다. 파란 버튼에는 `text-on-action`을 써야 합니다(CLAUDE.md에 적음).
