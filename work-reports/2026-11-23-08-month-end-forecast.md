# 월말 예상 지출을 정기 지출 기반으로 계산

- 날짜: 2026-11-23
- PR: #46

## 한 줄 요약
월간 대시보드의 '월말 예상 지출'이 월초 고정비 때문에 크게 부풀던 문제를 고쳤습니다. 이제 남은 정기 지출과 일상 지출 추세로 계산합니다.

## 왜 했나
- 기존 계산은 `지출 ÷ 지난 일수 × 월 일수`였습니다.
- 예를 들어 11/10에 월세 50만 원과 식비 10만 원을 썼다면 예상이 180만 원으로 나왔습니다. 월세가 한 달 내내 반복되는 것처럼 계산했기 때문입니다.
- 반대로 25일 보험료처럼 아직 나가지 않은 정기 지출은 반영하지 않았습니다.

## 무엇을 바꿨나
- `lib/monthEndForecast.ts`의 `forecastMonthEndExpense`를 추가했습니다.
  - 예상 = 이번 달 지출 + 아직 등록되지 않은 정기 지출 + 일상 지출의 하루 평균 × 남은 일수
  - 아직 등록되지 않은 정기 지출: 월간은 미적용 항목, 주간·격주는 남은 회차를 셉니다.
  - 일상 지출: 정기 내역과 카테고리·금액·설명이 같은 거래를 빼고 계산합니다.
- 대시보드에 '남은 정기 지출 N원 포함'을 보조 문구로 표시합니다.
- 위 예시는 이제 80만 원으로 나옵니다(월세 50만 + 식비 10만 + 남은 20일 × 1만).

## 확인한 방법
- 테스트 2개 추가(고정비를 늘리지 않음, 미적용 월간·남은 주간 회차 반영)
- `npm run verify` 통과(테스트 279개, 홈 번들 222KB로 예산 안)

## 남은 일·주의
- 정기 내역으로 만든 거래에는 표시가 없어서 카테고리·금액·설명으로 알아봅니다. 금액을 고친 거래는 일상 지출로 셉니다.
- 구독 목록은 거래를 만들지 않아 중복 위험이 있으므로 예측에 넣지 않았습니다.
- 카드 청구 예정액을 반영한 현금흐름(통장 잔액 기준) 예측은 계좌 잔액 기능(F3)과 함께 다룰 일입니다.
