# 대출 잔액 추적

- 날짜: 2026-11-23
- PR: #53

## 한 줄 요약
대출을 등록하고 '대출' 지출을 기록할 때 어느 대출을 갚았는지 고르면, 월간 대시보드가 대출별 남은 원금을 보여줍니다.

## 왜 했나
- 기능 분석 F5 항목입니다.
- 원금·이자 구분 입력은 이미 있었지만, 남은 원금은 추적할 수 없었습니다.

## 무엇을 바꿨나
- **데이터**
  - `Loan { id, name, balance, balanceAsOf, createdAt }`을 설정(`AppSettings.loans`)에 저장합니다.
  - 거래에는 `loanId`를 추가했습니다.
  - 백업 스키마와 로그인 병합(id 기준 합침)에도 반영했습니다.
- **계산:** `lib/loans.ts`의 `getLoanStatuses`를 추가했습니다.
  - 남은 원금 = 기준일의 남은 원금 − 기준일 이후 연결된 상환의 원금
  - 원금·이자를 나눠 적었으면 원금만, 나누지 않았으면 전액을 원금으로 셉니다.
- **거래 입력:** 카테고리가 '대출'이면 등록한 대출을 고를 수 있습니다(선택). 수정할 때 대출을 빼면 `loanId`도 지워집니다.
- **대출 관리 모달:** 대출을 추가·수정·삭제합니다.
  - 남은 원금을 고치면 그날이 새 기준일이 됩니다.
  - 이름만 바꾸면 기준일은 그대로입니다.
- **대시보드 '대출 잔액' 카드**
  - 대출이 있거나 '대출' 지출 기록이 있을 때 보입니다.
  - 위젯 설정에서 숨길 수 있습니다.
  - 아직 대출이 없으면 '대출 추가' 안내를 보여줍니다.

## 확인한 방법
- 테스트 3개 추가(기준일 이후 원금만 차감·다른 대출/수입 제외, 음수 방지, 모달 추가·이름 변경 시 기준일 유지)
- `npm run verify` 통과

## 남은 일·주의
- 대출 저장은 월급날 설정과 같이 대시보드에서 바로 `saveSettings`를 호출합니다. 실패하면 화면을 되돌리고 안내합니다.
- 이자율이나 만기로 상환 일정을 예측하는 기능은 없습니다.
- 계좌 잔액(#52)과 달리 순자산 합계에서 대출을 빼지는 않습니다.
