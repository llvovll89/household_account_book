- 예산 설정 → 홈 잔액 반영, 최근 내역 → 금액 수정 → 저장, 저장 후 피드백, 월간 상세 펼침, 주간 상세 펼침, 복귀 안내 → 가져오기 흐름 확인.
- 전체 테스트 127개, ESLint, TypeScript 및 프로덕션 빌드로 검증. 각 PR은 원격 검사 통과 후 병합.

## 실제 사용으로 확인할 것

입력 시간이나 재방문율이 개선됐다고 측정한 것은 아니다. 실기기 키보드와 실제 계정의 원격 동기화는 이번 브라우저 검증에 포함하지 않았다.

일주일 동안 자주 쓰는 지출의 입력 시간, 입력 중 포기한 이유, 예산 피드백의 유용성, 다음 주 재사용 여부를 확인한다. 주간 비교는 기록된 금액의 비교이며 실제 소비 전체나 절약 성과를 확정하지 않는다.

작업 시작 전부터 수정 중이던 `UX_REVIEW.md`는 변경하거나 커밋하지 않는다.
